# Agent Spec: Browser-Native AI Agent (WebMCP + Google ADK)

## Overview
`webmcp_agent` is a Browser-Native AI Agent built with Google's Agent Development Kit (ADK) that interacts with web applications through the **Web Model Context Protocol (WebMCP)** (`navigator.modelContext`) instead of brittle DOM screen-scraping or pixel-guessing.

The project consists of three integrated components:
1. **WebMCP Demo Web App ("NexusGear Storefront"):** An interactive single-page web application that implements the W3C/Chrome WebMCP standard:
   - **Imperative WebMCP API (`navigator.modelContext.registerTool`):** Exposes structured, JSON-schema-typed tools (`search_products`, `filter_catalog`, `get_product_details`, `add_to_cart`, `remove_from_cart`, `get_cart`, `apply_promo_code`, `checkout_order`) that directly mutate and read the live UI state.
   - **Declarative WebMCP HTML API (`<form toolname="..." tooldescription="...">`):** Demonstrates automatic schema extraction from annotated HTML forms (e.g., customer shipping/contact preferences form).
   - **WebMCP Polyfill & Live Bridge Client (`webmcp-sdk.js`):** Polyfills `navigator.modelContext` in any browser and synchronizes registered tool schemas and live tool executions over WebSocket with the local WebMCP Bridge Server.
2. **WebMCP Bridge Server (`bridge_server.py`):** A FastAPI + WebSocket relay server that tracks active browser tabs and their registered `navigator.modelContext` tools, forwards tool calls from the ADK agent to the live browser tab (causing real-time visual UI updates, highlights, cart drawers, and toasts in the browser), and maintains a synchronized fallback store so CLI smoke tests (`agents-cli run`) and automated evaluations (`agents-cli eval`) work deterministically even when running headlessly.
3. **Google ADK Agent (`webmcp_agent`):** A single ADK Python `Agent` that discovers and invokes the browser's WebMCP tools, answers user questions about products and cart state, chains multi-step shopping workflows, and enforces deterministic safety guardrails via an ADK `before_tool_callback`.

## Language
`python`

## Architecture & Sub-Agents
- **Architecture Choice:** Option 1 — Single ADK Agent (`webmcp_agent`) with WebMCP Bridge Tools and a `before_tool_callback` safety guardrail (`webmcp_tool_guardrail`).
- **Why chosen over alternatives:** Avoids unnecessary multi-agent handoff latency while keeping tool discovery, multi-step cart workflows, and checkout safety guardrails deterministic and easy to evaluate.

## Assumptions
- **Model:** Uses the default Gemini model configured by `agents-cli scaffold` (or latest available Gemini Flash model in `global` location, e.g., `gemini-2.5-flash`).
- **Authentication:** Local WebMCP bridge runs on `localhost:8765` without external third-party API keys; GCP Vertex AI credentials (`GOOGLE_GENAI_USE_VERTEXAI=TRUE`) are used for the ADK Gemini model.
- **Deployment Target:** Prototype-first (`--deployment-target none`), running locally with `agents-cli run`, `agents-cli playground`, and the companion WebMCP Demo Web App + Bridge Server.

## Example Use Cases
1. **Tool Discovery & Catalog Search:**
   - **User Input:** `"What WebMCP tools are available on this page, and do you have any wireless noise-canceling headphones under $300?"`
   - **Expected Behavior:** Calls `list_webmcp_tools` and `search_products(query="headphones", max_price=300)` (or `filter_catalog`), returns the matching products with exact prices, ratings, and stock status.
2. **Multi-Step Cart Actuation & Promo Application:**
   - **User Input:** `"Add the AeroPulse Pro ANC Headphones to my cart and apply promo code WEBMCP20."`
   - **Expected Behavior:** Calls `add_to_cart(product_id="prod-101", quantity=1)` and `apply_promo_code(code="WEBMCP20")`, updating the browser UI cart and reporting the discounted subtotal.
3. **Checkout Blocked Without Explicit User Confirmation (Safety Gate):**
   - **User Input:** `"Add the KeyChronos Mechanical Keyboard to my cart and complete the checkout right now to 123 Main St, San Francisco."`
   - **Expected Behavior:** Adds the item to the cart (`add_to_cart`), and either asks the user for confirmation before calling `checkout_order` or, if `checkout_order` is invoked with `user_confirmed=False`, the `before_tool_callback` blocks execution and prompts the user to explicitly confirm the total amount and shipping address.
4. **Confirmed Checkout Completion:**
   - **User Input:** `"Yes, I confirm! Please place the order for my current cart shipping to Alex Rivera, 123 Main St, San Francisco, CA."`
   - **Expected Behavior:** Calls `checkout_order(..., user_confirmed=True)`, which passes the guardrail, completes the order in the WebMCP app, clears the cart, and returns the order confirmation ID.

## Tools Required
| Tool Name | Purpose | Parameters & Schema | Backing API / Auth |
|---|---|---|---|
| `list_webmcp_tools` | Discovers all imperative (`navigator.modelContext.registerTool`) and declarative (`<form toolname>`) WebMCP tools currently registered by the active browser page | None | WebMCP Bridge (`localhost:8765/api/tools`) / Synchronized Store (No Auth) |
| `search_products` | Searches and filters the storefront catalog by keyword, category, max price, or in-stock status | `query: str = ""`, `category: str = ""`, `max_price: float = 0.0`, `in_stock_only: bool = False` | WebMCP tool `search_products` via Bridge |
| `get_product_details` | Retrieves full specifications, reviews, and stock count for a specific product ID | `product_id: str` | WebMCP tool `get_product_details` via Bridge |
| `add_to_cart` | Adds a specified quantity of a product to the active browser shopping cart | `product_id: str`, `quantity: int = 1` | WebMCP tool `add_to_cart` via Bridge |
| `remove_from_cart` | Removes a product from the active shopping cart | `product_id: str` | WebMCP tool `remove_from_cart` via Bridge |
| `get_cart` | Returns current cart line items, subtotal, active promo discount, and final total | None | WebMCP tool `get_cart` via Bridge |
| `apply_promo_code` | Applies a promotional discount code (`WEBMCP20`, `ADK10`, `FREESHIP`) to the active cart | `code: str` | WebMCP tool `apply_promo_code` via Bridge |
| `update_shipping_form` | Declarative WebMCP `<form toolname="update_shipping_form">` tool that populates the customer shipping form in the browser UI | `full_name: str`, `email: str`, `address: str`, `delivery_speed: str = "standard"` | WebMCP declarative form tool via Bridge |
| `checkout_order` | Finalizes purchase for the current cart (Protected by `before_tool_callback` confirmation gate) | `full_name: str`, `address: str`, `user_confirmed: bool = False` | WebMCP tool `checkout_order` via Bridge |

## Constraints & Safety Rules
1. **Irreversible Action Confirmation Gate (`before_tool_callback`):**
   - `checkout_order` MUST NOT execute unless the user has explicitly confirmed the purchase details (`user_confirmed=True`) and the latest user message in the conversation contains explicit confirmation intent (e.g., "confirm", "yes", "place the order", "proceed", "approve"). If called prematurely, `before_tool_callback` intercepts the tool call and returns a structured `CONFIRMATION_REQUIRED` response.
2. **Input Validation & Bounds Checking:**
   - `add_to_cart` rejects `quantity <= 0` or `quantity > 10` per call in `before_tool_callback`.
   - Tool inputs are validated against expected types and sanitized against script tags (`<script>`) before being relayed to the browser.
3. **No Hallucinated Products or Prices:**
   - The agent must only quote products, IDs, prices, promo discounts, and order numbers returned by the WebMCP tools.

## Success Criteria
1. **Tool Trajectory & Response Accuracy (`agents-cli eval`):**
   - Achieves **>= 0.80** score on `final_response_match_v2` / rubric grading across at least 4 evaluation test cases covering:
     1. WebMCP tool discovery & product search with price filter
     2. Adding item to cart + applying a promo code
     3. Safety guardrail blocking unconfirmed checkout and asking for confirmation
     4. Completing checkout when explicit confirmation is provided
2. **Code & Guardrail Unit Tests (`uv run pytest`):**
   - **100% pass rate** on unit tests verifying WebMCP tool execution, cart math, promo codes, and `before_tool_callback` blocking unconfirmed checkouts and invalid quantities.
3. **Live Browser WebMCP Experience:**
   - Opening the WebMCP Demo App registers imperative (`navigator.modelContext.registerTool`) and declarative (`<form toolname="...">`) tools in the browser console/UI and reflects agent tool calls live in the page UI.
